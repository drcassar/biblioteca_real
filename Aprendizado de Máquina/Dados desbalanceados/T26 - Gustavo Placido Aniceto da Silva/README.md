# Estratégias para lidar com dados desbalanceados em problemas de classificação

Notebook didático em Python sobre classificação com classes desbalanceadas, construído em torno de um problema fictício de triagem de peças defeituosas. O material parte dos conceitos básicos e avança, passo a passo, até a comparação de estratégias de reamostragem, com explicações em linguagem acessível e os termos técnicos necessários.

## Estrutura do notebook

O conteúdo é organizado em seções que se encadeiam: cada conceito é explicado em texto antes de aparecer no código, e cada resultado é seguido de uma interpretação.

| Seção | Conteúdo |
|---|---|
| **1. Fundamentos** | Conceitos necessários para acompanhar o restante: tipos de dados, desbalanceamento, modelos, métricas, divisão dos dados e boas práticas de avaliação. |
| **2. Criação do dataset** | Apresentação do problema, preparação do ambiente, geração dos dados sintéticos, separação das amostras e exploração inicial. |
| **3. Modelos de classificação** | Introdução de diferentes classificadores, cada um explicado, treinado e avaliado de forma padronizada. |
| **4. Resolução do problema** | Comparação das estratégias de reamostragem sob um protocolo de avaliação definido previamente, avaliação final e discussão dos limites da solução. |
| **Apêndice A: Matemática** | Formalização matemática dos conceitos, ligada às ideias do texto. |
| **Apêndice B: Glossário** | Definição dos termos técnicos, matemáticos e de código usados ao longo do material. |
| **Referências** | Bibliografia, documentação das bibliotecas e registro do apoio de IA na elaboração. |

### Como o material foi pensado

- **Explicar antes de executar:** cada bloco de código é precedido por uma explicação e seguido de uma leitura dos resultados.
- **Exemplos numéricos simples** para ilustrar os conceitos antes de aplicá-los aos dados.
- **Dados sintéticos:** nenhum arquivo externo é necessário, e o experimento é reprodutível.
- **Linguagem acessível com rigor técnico:** a matemática e o glossário ficam em apêndices, para não interromper a leitura principal.
- **Limites declarados:** o notebook indica o que os resultados mostram e o que não permitem concluir.
