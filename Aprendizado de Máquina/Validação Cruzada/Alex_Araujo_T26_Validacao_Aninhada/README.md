# Enigma da Esfinge: Validação cruzada aninhada

Esta é a primeira das duas entregas da disciplina de aprendizado de máquina ministrada pelo prof. Dr. Daniel R. Cassar para a turma de 2026 da Ilum escola de ciência. Ela tem como propósito explicar o método da validação cruzada aninhada (VCA, para fins de praticidade), com sua implementação focada em problemas de classificação binária a fim de limitar o escopo do projeto.

## Metodologia

O caderno é separado em duas grandes partes, a primeira constrói o problema gradualmente, construindo uma linha de raciocínio até chegar no método principal. A última, por sua vez, junta os métodos apresentados na parte anterior para implementar a VCA para um problema de classificação binária. O código desta parte é independente dos demais produzidos noutras sessões, com explicações detalhando os propósitos de cada função e com funções generalizadas para aplicar outros modelos de aprendizado de máquina para problemas de classificação binária.

Embora o foco não tenha sido criar um módulo do python que pudesse ser reutilizado, o código foi pensado de maneira a facilitar adaptações para outras aplicações.

## Os arquivos

A entrega está dividida em dois arquivos: ``esfinge_v2.ipynb`` é o caderno jupyter principal, enquanto ``water_potability.csv`` é o conjunto de dados usado no caderno.
